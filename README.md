Student Grade Calculator

A simple Python program that reads the names and exam grades of 5 students and calculates each student’s average and letter grade.

Features
Average is calculated with a weighted formula: midterm 40%, final exam 60%.
Letter grade is assigned from the average (AA to FF).
Pass/fail check: an average of 60 or higher passes.
Input validation: only numbers from 0 to 100 are accepted. The program asks again if the input is invalid.
Usage
bash
python grades.py

Enter a name, then the midterm and final grades for each of the 5 students.

Requirements
Python 3
